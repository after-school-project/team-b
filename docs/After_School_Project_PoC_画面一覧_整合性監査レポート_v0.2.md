## 4. 設計上の判断と残る工程

今回の資料調整で、却下後の再申請・本人の取り下げ履歴もPoC対象とした。既存MVPの操作契約に合わせて画面へ反映している。

親質問削除後は削除案内と残存回答を表示し、削除済み親への新規回答を受け付けない設計案とした。イベント自己申請の一覧表示とAD-14の画面構成も設計案として記載している。

Markdown許可構文、公開設定、ホーム掲載件数と順序はDES-01／03で初期設計済み。認証方式と発行・配布・再発行の方針はTECH-01〜04で決定済み。具体的な固定バージョン・発行API・連絡先・配布担当者・受渡方法と各画面の詳細なレイアウトは、基盤構築・実演準備・各機能の実装前に具体化する。学校承認・本人確認・運営責任・学校管理者の追加／退任／緊急復旧等は原資料の学校協議事項として管理する。

本確認で検査したのは資料の記載と参照関係。アプリ・DB・APIの実装検証はロードマップの各段階で実施する。
