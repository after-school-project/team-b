# After School Project ドキュメント案内

更新日 2026-11-12

企画・要件・PoC設計に関する資料の一覧です。各資料の役割と、確認したい内容に応じた参照先をまとめています。

初めて読む場合は、企画概要 → 仕様検討書・要望書 → MVP機能要件定義書 → ロール・権限マトリクスの順に読むと、目的・利用者・機能・運営上の制限を把握できます。

PoCの開発を進める場合は、実装ロードマップで対象範囲と現在地を確認し、技術決定書 → 画面一覧 → 画面遷移・共通認可・DB設計 → API設計を参照してください。

MVPの要件・権限を土台として、PoCで実装する範囲と省略はロードマップの決定記録、採用技術・認証は技術決定書、画面・認可・保存モデル・API契約は各設計書で確認できます。画面IDと要件IDは同じ形式の番号を含むため、参照時にどちらのIDかを明記します。

学校協議事項はMVP機能要件定義書11節と権限マトリクス8節、実装前に具体化する項目はロードマップと各設計書の次工程・後続設計の記載を参照してください。
